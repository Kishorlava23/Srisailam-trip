# Srisailam Trip Website

A personal travel story website built from the Srisailam trip story and uploaded trip photos.

## Project structure
- `index.html` — page content
- `css/style.css` — responsive design
- `js/script.js` — page interactions
- `images/` — your trip photos

## Publish with GitHub Pages
Upload the contents of this folder to a GitHub repository, then enable **Settings → Pages → Deploy from a branch → main → /(root)**.

The `index.html` file must remain in the repository root.
